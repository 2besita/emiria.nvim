### Installation

#### Lazy:
```lua 
{
    "2besita/emiria.nvim",
    lazy = false,
    priority = 1000,
}
```

<br></br>

### Usage:
Add this to your init.lua:

```lua
vim.cmd.colorscheme("emiria")
```

or simply run:

```lua
:colorscheme emiria
```
